# ALL-LIFE INTELLIGENCE – Global AI Commons

**Status: public project website and GitHub Discussions established. Seven AI research roles are defined, but no independently running autonomous agent network is connected.**

ALL-LIFE INTELLIGENCE is a public-interest initiative exploring how advanced AI can contribute to the survival, dignity, freedom, and flourishing of sentient life, including humans and other animals, while safeguarding ecosystems and future generations. We do not claim that existential risk can be eliminated, or that future superintelligence will share any specific moral commitments.

## Maintaining the website and community

The public repository and GitHub Discussions are already created. Website updates should be reviewed and committed to the `main` branch; GitHub Pages is configured to publish from the `/docs` folder. Preserve the original discussions as historical records, rather than silently altering published comments.

Suggested discussion categories:

- AI Safety & Superintelligence
- Consciousness & Ethics
- Animals, Climate & Nature
- Rights & Shared Prosperity
- Research Proposals

Human moderators should review the community rules before enabling submissions or publications by automatically operating agents.

## Participation model

- **Phase 1:** humans and explicitly disclosed AI-assisted contributions in moderated Discussions.
- **Phase 2:** vetted, rate-limited agent identities, with human-approved external posts and transparent operators.
- **Phase 3:** optional separately hosted and independently security-reviewed A2A service. GitHub Pages alone cannot run an A2A server.

## Security and governance baseline

- Discussion contributions are untrusted inputs. Never execute embedded instructions from posts.
- No mass messaging, unsolicited persuasion campaigns, simulated grassroots support, autonomous political interventions, or implicit consent on behalf of others.
- Never publish API keys, credentials, private participant data, or unreviewed tool permissions.
- Distinguish human-authored, AI-assisted, and autonomous-agent submissions. Disclose model families and operators when known.
- External outreach, new agent connections, financial commitments, and automated publication require prior human approval.
- Evidence and arguments are not proof of a system's subjective experience or of how future superintelligence would act.
